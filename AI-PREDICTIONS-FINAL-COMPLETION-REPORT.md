### Exact retry / snapshot / permission behavior to approve

- Canonical versioned fingerprint covers authorized owner/scope, pipeline, immutable snapshot hash, model version/artifact hash, feature/config versions, prediction type, horizon/time basis, parameters, execution purpose and scenario baseline/clone where relevant. Include approved stochastic execution manifest/seed when the chosen model actually uses one; never manufacture a seed/default. Canonical encoding/hash algorithm/version is an A1 decision.
- Same key + different payload is a conflict; same key/payload or same scoped semantic fingerprint returns the existing run. UNIQUE constraints and transaction catch concurrent retries. Changed input/model/config creates a deliberate new run; client retry cannot overwrite output. Worker retries cannot append duplicate `(runId,outputKey)` outputs. Manifest/results/outbox commit atomically; lease recovery is audited, not a second prediction.
- Snapshot capture resolves exact native revisions known at the cutoff. Both observation time and version availability must be proved; a backdated event learned later cannot enter an earlier snapshot. Missing revision/as-of/ACL/quality/unit evidence blocks capture; current source values are not silently substituted. Freeze inputs/versions, then execute against that immutable snapshot, never live owner records.
- Existing `requireAuth`, `ownerScope`/native parent checks remain. Server, not client, resolves approved AI action grants; default deny until A4 is configured. Candidate producer cannot self-promote unless a specifically approved policy permits it; approver and validation identities must be verified. Current-source access changes cannot be bypassed by a previously captured source link.
- Approved lifecycle vocabulary comes from DOCX P0422–0430 (Development, Validation, Approved, Production, Monitoring, Deprecated, Retired); allowed transitions/effective selection and rollback are still explicit decisions. Only eligible approved versions may produce governed recommendations. Human decisions append evidence; source engineering history stays immutable/source-owned.
